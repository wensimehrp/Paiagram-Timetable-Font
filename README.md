Paiagram-Timetable-Font is based on
[XF_Nstf](https://github.com/akashiyaki01c/XF_Nstf) created by akashiyaki01c.

## Difference with XF_Nstf

- Improved hinting
- Added extra glyphs
- Modified glyphs (added descenders)

## Building

Requirements:

- [FontForge](https://fontforge.org/)
- Make
- Typst & internet connection (for generating preview page)

```bash
make
```
